# 本机演示与自测

运行环境、依赖安装和默认密钥配置见 [README](../README.md) 与 [模型接入说明](MODEL-CONNECTION.md)。当前使用入口为 `python -m scripts.start_dev` 启动后的 `http://127.0.0.1:5173/`；后端端口不是使用者页面。

## 无密钥的基础演示

1. 使用新的浏览器配置，创建仅供演示的本机加密资料库。
2. 输入明确标注为虚构的文字，检查保存、回看和历史。
3. 导出 `.bingli` 加密备份，再在独立演示资料库中检查恢复。
4. AI 未配置时应明确失败，已保存的原话与媒体原件应继续可查，不能展示伪造的成功结果。

恢复口令、导出的备份和浏览器资料不随源码分享。仓库中的合成 WAV/PNG 说明见 [合成素材](../data/synthetic/selftest/README.md)。

## 启用 AI 后的演示

在本机 `.env` 配置自己的文字和媒体服务后重启。录音、识别文字、照片原件核对、AI 整理与人工确认应分别检查；真实服务调用可能产生费用。只使用合成素材或获得明确授权的测试材料，不在公开仓库留下真实健康资料、原始响应、令牌或内部账号信息。

离线软件回归方法见 [验证方法](VALIDATION.md)。旧兼容服务的 HTTP 自测工具仍保留在 `scripts/`，它们不代替当前浏览器完整流程的验收。
