# 项目范围

当前公开产品说明见 [PRODUCT.md](../PRODUCT.md)，使用入口见 [README](../README.md)，当前架构见 [ARCHITECTURE.md](ARCHITECTURE.md)。实现合同以 [API.md](API.md) 和 [contracts/api.ts](../contracts/api.ts) 为准。

本项目用于本机记录健康变化、保留原话与媒体、人工核对、回看历史和准备就诊沟通材料。默认健康资料加密保存在使用者自己的浏览器中；在线服务只处理明确提交的 AI 请求。

公开副本不保留旧开发分工、内部 PR/分支交接或个人在线联调记录。`docs/sdlc/` 中保留的无个人信息规格资料仅作设计背景，不可据此推断功能已经验收或替代当前代码。

本项目不提供诊断、处方或自动改药。复杂医学图像属于 [当前范围之外](team/P1-COMPLEX-IMAGE-RECOGNITION.md)。软件测试、合成案例和公开病例均不构成临床效果证明。
