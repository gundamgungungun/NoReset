# 开发与检查

```bash
git clone https://github.com/gundamgungungun/NoReset.git
cd NoReset
```

安装和启动方法见 [README](../../README.md)。配置只保存在本机 `.env`；不共享访问令牌、恢复口令、健康资料或应用运行目录。

修改前检查当前工作区；保持 API 合同、调用方和测试一致。分支和 PR 使用当前仓库，不沿用旧开发账号或内部历史分支。检查和证据范围见 [验证方法](../VALIDATION.md)。

贡献说明应描述问题、改动、实际验证和限制。公开 Issue 与 PR 只使用虚构材料；病例来源和第三方版权声明继续保留。
